# ECHOGLASS — Level 1 Prototype

Something intelligent named **Echo** is trapped inside the player's phone.

Open [`echoglass/index.html`](./echoglass/index.html) on a phone (portrait) or desktop.

## Controls
- **Tilt** the phone (or WASD / arrows on desktop) to change gravity
- **Tap** empty space for a shockwave
- **Hold** ~0.4s for a temporary containment field
- **Drag** the security gate along its track

## Level 1 — First Contact
Help Echo restore reactor power, then contain Echo before it escapes through the conduit.

## Assets
Uses the supplied SVG pack in `echoglass/assets/` (echo, energy cell, reactor, conduit, pad, gate).
